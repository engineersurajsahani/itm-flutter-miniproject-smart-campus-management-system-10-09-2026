# Smart Campus Management System

A centralized system to manage students, faculty, courses, attendance, notices, and academic records. The platform supports Admin, Faculty, and Student roles with secure authentication and authorization.

## Key Focus Areas
- Role-based access control (RBAC)
- Student & faculty management
- Attendance & academic records
- Secure REST APIs

## Tech Stack
- Flutter
- REST API
- RBAC
